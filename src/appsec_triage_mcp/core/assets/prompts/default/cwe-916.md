## Password storage review

Trace the value from password input to storage and later verification. Check
the password-hashing primitive, salt handling, cost or work factor, and whether
the application can upgrade old hashes. MD5, SHA-1, fast SHA-2, unsalted
digests, and low-cost configurations are insufficient for password storage.

Use `confirmed` only when the complete path and unsuitable construction are
grounded in code. Use `false_positive` only when a password-specific password
hashing function and its parameters are visible. Use `unknown` when the
storage or verification path is hidden. Do not make network requests.
